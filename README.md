# Brieflark 한 줄 설치

Brieflark 설치를 안내한 사람이 보내 준 **한 줄**을 실행하는 스크립트예요. Windows는 `install.ps1`(PowerShell), Mac은 `install.sh`(터미널)를 써요.

- 이 저장소에는 설치 스크립트만 있어요. 비서 코드는 초대받은 사람만 받을 수 있는 비공개 저장소에 있어요.
- 한 줄은 이 저장소의 **특정 커밋**에 있는 스크립트를 받아, 그 내용의 SHA256이 한 줄에 적힌 값과 같을 때만 실행해요. 다르면 아무것도 실행하지 않아요.
- 스크립트는 단계마다 무엇을 어디에 설치할지 보여 주고 Enter를 받은 뒤 진행해요. 비서 코드를 받은 뒤에는 내장된 서명 키로 릴리스 서명을 확인하고, 확인에 실패하면 설치 마법사를 실행하지 않아요.
- Windows: PowerShell은 **관리자가 아닌 보통 창**으로 열어 주세요.
- Mac: **터미널** 앱에서 실행해요. `sudo`를 붙이지 마세요. 모든 도구를 내 홈 폴더 안에 설치해요(Apple 명령줄 도구가 없으면 Apple 설치 창만 따로 떠요).

한 줄은 이 README에 적지 않아요. 설치를 안내한 사람에게 받은 한 줄만 쓰세요.
